# Additional Notes:
# 
# For Windows users, you also need to install:
# 
# 1. Tesseract OCR Engine:
#    Download from: https://github.com/UB-Mannheim/tesseract/wiki
#    Install and add to PATH, or set path in script
#    Default: C:\Program Files\Tesseract-OCR\tesseract.exe
#
# 2. Poppler (for pdf2image):
#    Download from: https://github.com/oschwartz10612/poppler-windows/releases/
#    Extract and add bin\ folder to PATH
#    Example: C:\poppler-xx.xx\Library\bin
#
# For Vietnamese OCR support:
#    Download Vietnamese language data for Tesseract:
#    https://github.com/tesseract-ocr/tessdata/blob/main/vie.traineddata
#    Place in: C:\Program Files\Tesseract-OCR\tessdata\
